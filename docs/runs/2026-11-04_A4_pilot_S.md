# 2026-11-04 · A4 pilot：确定训练步数 S

**状态：** 完成，S 冻结为 **500**

## 一、实验设计

| 项 | 值 |
|---|---|
| 目的 | 按 `specs/06` §2 的规则确定全项目统一训练步数 S |
| 数据 | `data/curated/real_300.jsonl`（300 句，376 实体） |
| 种子 | **7**（刻意避开正式种子 13/23/33，避免污染） |
| 扫描 | S ∈ {100, 200, 300, 500}，batch 2，lr 2e-5 |
| 评测 | 完整 dev 1,172 句，阈值固定 0.80 |

**判据（来自 specs/06）：** 取"各 arm 的 dev Micro-F1 均未出现连续两点下降"的最大 S。

## 二、结果

| S | epoch | 训练时长 | Precision | Recall | **Micro-F1** | 扫描最优 |
|---:|---:|---:|---:|---:|---:|---|
| 100 | 0.67 | 56.7 s | 0.6652 | 0.8908 | 0.7617 | 0.90 → 0.7775 |
| 200 | 1.33 | 70.1 s | 0.7197 | 0.8979 | 0.7990 | 0.90 → 0.8116 |
| 300 | 2.00 | 78.9 s | 0.7596 | 0.8929 | 0.8209 | 0.90 → 0.8330 |
| **500** | 3.33 | 113.1 s | 0.7908 | 0.8879 | **0.8366** | 0.90 → 0.8424 |

**曲线单调上升，没有出现任何掉点**，因此判据中的"连续两点下降"不成立，按规则取网格内最大者：**S = 500**。

逐档增量：100→200 **+3.7**、200→300 **+2.2**、300→500 **+1.6**（步数翻倍，收益明显递减）。

## 三、观察

1. **全部提升来自 Precision**（0.6652 → 0.7908，+12.6 点），Recall 反而微降（0.8908 → 0.8879）。步数越多，模型越"谨慎"：早期是宁可乱报，后期学会收敛。这与 E1 首轮（S=300）观察到的"召回大幅提升"并不矛盾——两者都指向同一个方向：**模型先学会多报，再学会收窄**。
2. **收益递减明显**：从 300 到 500 步，训练时间 +43%，F1 只涨 1.6 点。若继续加到 1000 步，预计收益会进一步衰减，且 E1 只有 300 条样本，过拟合风险上升。
3. **种子噪声不可忽视**：同为 S=300，pilot seed 7 得 0.8209，正式 seed 13 得 0.8325，差 1.2 点。而 S=500 的三个正式种子标准差只有 0.45 点——**训练步数增加后种子间方差显著收窄**，这对结论稳健性是好事。
4. **扫描最优始终在 0.90**（所有 S 档都是），说明固定 0.80 是偏保守的选择，代价约 0.5–1.5 点。这是 `specs/07` §2 的已知代价。

## 四、决策与影响

| 项 | 决定 |
|---|---|
| 统一训练预算 S | **500**（E1 / E2 / E3 全部使用） |
| 先前 E1 seed 13 @ S=300 的 checkpoint | 作废，已用 S=500 重训 |
| `results/experiments.csv` | 已按 S=500 重建 E1 三行，旧 S=300 行删除（原结果归档在 `D:\pt_ner_work\results\e1_s13_dev.*` 与本目录旧记录） |
| 台账新增列 | `max_steps`，避免以后再出现"同名不同预算"的混淆 |

**尚未满足的部分：** 判据原文要求"E1 与 E2 的 dev F1 均不掉点"，但 E2（合成数据）还没生成，本次只能用 E1 定 S。待 E2 数据齐备后需回验一次：若 E2 在 500 步已明显过拟合，应下调 S 并重跑全部 arm。
