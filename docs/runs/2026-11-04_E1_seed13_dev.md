## 四、观察

1. **提升主要来自召回**：精度几乎不动（0.768 → 0.769），召回涨了 17.6 点，FN 从 375 降到 231。说明微调教会模型"多报"，但没牺牲精确率。
2. **固定 0.80 对微调模型偏低**：扫描显示 0.85 → 0.8371、0.90 → **0.8448**，即在 0.80 上固定把 **+1.2 点**留在桌上。这是统一阈值的已知代价（见 `specs/07` §2），必须在报告中作为敏感性分析披露。
3. **LOC 进步最大（+11.2 点）**，仍是精度导向；**ORG 依然最弱（0.7361）**，虽然涨了 8 点，但 FP 184 个，仍是主要错误来源。
4. **Type Error 从 45 升到 56**：微调让模型更愿意报实体，类别混淆随之增加。
5. **CI 宽度 0.052**，比 E0 的 0.067 窄，且两个区间不重叠（[0.7148,0.7814] vs [0.8044,0.8568]），提升是稳的。
